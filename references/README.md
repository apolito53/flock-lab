# References

## Related repositories

- [WebGPU Particle Lab](https://github.com/apolito53/web-gpu-lab) — raw WebGPU compute and rendering experiment. Useful reference for WGSL, storage buffers, 3D projection, trails, timestamp profiling, and high-count particle benchmarks. It is not currently a boids implementation.
- [Nova Projects: The Space Between Wings](https://github.com/apolito53/nova-projects/tree/main/projects/2026-11-11-the-space-between-wings) — original 160-bird local-rule murmuration experiment.
- [Nova Projects: The Flock Lab preview](https://nova-projects-xi.vercel.app/projects/2026-11-16-the-flock-lab) — earlier hosted 2D leadership and gravity sandbox.

## Conceptual starting points

- Craig Reynolds, [Boids: Background and Update](https://www.red3d.com/cwr/boids/) — foundational local-neighbor flocking model.
- [Days Gone](https://www.playstation.com/en-us/games/days-gone/) — a useful game-design reference for large zombie hordes moving through an environment.
- [World War Z](https://www.focus-entmt.com/en/games/world-war-z) — a useful reference for dense swarms, climbing piles, and scale-dependent simulation.
